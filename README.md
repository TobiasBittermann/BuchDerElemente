## Die Story

Die Kampagne spielt auf dem Kontinent Kiribati. Die Spieler starteten auf Grashkas Piratenschiff und strandeten auf der Insel [Yll](Kiribati/Länder/Yll.md). Es gelang ihnen das Buch der elemente zu finden und sie entkamen von der Insel. Sie strandeten an der sübküste von [Kharotai](Kiribati/Länder/Kharotai/Kharotai.md).

Die Party macht sich auf nach [Eisenhütte](Kiribati/Länder/Kharotai/Städte/Eisenhütte/Eisenhütte.md). Sie trefen auf dem Weg den Händler [Caleb Veltri](NPCs/Caleb%20Veltri.md) der von Gnolls angegriffen wurde. Die Party besiegt die Gnolle und bringt alle noch heilen Waren [Caleb Veltri](NPCs/Caleb%20Veltri.md) zurück. Gemeinsam erreichen sie [Eisenhütte](Kiribati/Länder/Kharotai/Städte/Eisenhütte/Eisenhütte.md).
